ID 29

Heat Pump ready

Clock-synced sidechain ducking envelope

Faders

  • Main — Release (up = faster recovery)
  • Alt — Duck depth (red LED)
  • Third — Clock division (1/1 … 1/32)

Jack params

  • Jack: CV Out / CV In
  • CV Dest: Depth · Release · Duck
  • Dest colors: Red · Yellow · Cyan
  • CV Att 0–100%

Buttons

  • Short — Manual duck trigger
  • Long — Mute (freeze level; no snap to idle; dim red button)
  • Shift+Short (CV Out) — Cycle clock division
  • Shift+Short (CV In) — Cycle CV Dest (flash)
  • Shift+Long — Invert duck direction

LEDs / other params

  • Button metronome Mid→Low per division · Mute = dim red (not off)
  • 1/1 uses Color param
  • Invert: white ↔ off fade
  • Color, Range, MIDI CH/CC, NRPN, MIDI Out

Manual. Clock-synced ducking envelope: each division pulse ducks, then recovers by Release. Depth sets how far. Mute freezes the envelope at its current level (clock triggers discarded). Invert flips duck direction. Third sets division directly; Shift+Short cycles division (CV Out) or CV Dest (CV In). CV Att scales modulation.

ID 30

Grooves ready

Multi-genre MIDI drum grooves with swing

Faders

  • Main — Density (extra hits)
  • Alt — Genre scrub (shared axis with Chord Vamp)
  • Third — Swing (capped by Swing max %)

Genres

  • Dub → Disco → House → Techno → Trip-Hop → Hip-Hop → Jungle → UK Garage → Dubstep
  • LEDs: continuous open red→yellow→green→cyan→blue spectrum (same as Chord Vamp)
  • Sound morphs continuously between neighboring genres along the axis

Buttons

  • Short — Mute (notes off)
  • Shift+Tap — Genre fill until next downbeat (break at high density)
  • Shift+Hold — Drum solo while held: 4-bar phrase (build → busier → peak → turnaround); resolves on release
  • Long — Reset to downbeat

Jack params

  • Jack: CV Out Any · CV Out Stacked · CV In Density · CV In Feel · CV In Reset
  • Stacked sums families — hats 1, snare 2, kick 4 of 10 units; Open Hat counts as hats, Clap as snare, toms as kick
  • The jack follows the groove, so it still pulses with every note switched off
  • Range, CV Att

Params / LEDs

  • Notes: Kick, Snare, Hats, Open Hat, Low Tom, High Tom, Clap — note 0 switches a voice off
  • MIDI Ch is the base for all seven; Ch Map overrides it per voice (7 packed nibbles, 0 = follow base)
  • Groove, Swing max % (negative = reverse swing), GATE %, MIDI Out
  • Groove = pocket: 0 is dead on the grid; up adds per-family ms drift (kick tight → hats loosest), velocity bow and walking ghosts
  • GATE % is per voice — closed hats choke inside their step, open hats and toms may ring past it; CV pulse stays inside the 16th
  • Button Main: genre hue sat half→full (density) + bar lightness; hit dips kick −50% / snare −30% / hats −10%
  • Button Third: White→Color→Red (swing); same voice-weighted hit dips
  • Button Alt: committed genre hue (Top/Bottom = live fader meters; color changes only after latch pickup)

Manual. Genre MIDI drums on the global clock (9 shared genres with Chord Vamp, including Jungle). Density reveals hits; Shift+Fader scrubs genre on the shared red→blue spectrum — button hue follows the latched genre (meters show live fader until pickup) while neighboring genres morph continuously; Button+Fader = Swing (capped by Swing max %). Shift+Tap plays a dedicated genre fill (or break at high density) that resolves on the next downbeat — Techno machine-guns, Hip-Hop and Jungle roll the snare, Dub and Dubstep answer sparsely — with velocity crescendoing toward the bar line, independent of the Density fader. Shift+Hold escalates into a drum solo that plays a four-bar phrase rather than looping the fill: an open build, a busier bar, a peak, then a turnaround that drops back to the sparse end-weighted figure and breathes. Each solo bar carries its own accent mask — the weight sits on the one and the backbeat, Feel only adds human jitter around it instead of randomising the dynamics — and every figure keeps rests and trades kick against snare rather than stacking them. Feel also opens ghost drags on the step right after a hit, so the fill-ins read as flams off the figure. Groove is the pocket control for the main pattern too, not only for the gestures: at zero every voice sits exactly on the grid, so Grooves locks tight against other Faderpunk apps. Turning it up opens a millisecond pocket in which each family drifts by its own amount — the kick stays tightest, the snare leans back into the backbeat, the hats carry the widest jitter — scaled by how tight the genre is, so Techno stays surgical while Hip-Hop and Trip-Hop drag audibly. Higher Groove also bows velocity across the bar and walks which ghost hits Density reveals, so repeated bars stop reading identically. Note lengths are per voice as well: closed hats choke inside their own step so they never smear, while open hats and toms are allowed to ring past the 16th; the CV pulse always stays inside the step even when the MIDI note is longer. Genre character stays intact: Techno rolls 16th kick bursts against clap stabs, Jungle chops the amen skeleton (kick on 1 and 3e, snare answering on the e), Dubstep keeps its half-time anchor, Dub and Trip-Hop stay wide open. Letting go drops straight into the end-weighted fill for the rest of the bar, so the solo always lands on the one. Releasing keeps either gesture running to the next downbeat so it always resolves. Above roughly 60 % density the same gesture reads subtractively and plays a break instead — the floor drops out (Techno keeps the kick, House the hats, Dub goes near-silent) and a late snare pickup hands the groove back on the one. Each genre carries three fill, three break, and three solo figures; low Feel locks to one, higher Feel rolls between them (same Die mix as Bassment). The button shows the gesture: bright white while filling, dim white while breaking. Watch the button: Main density ramps genre hue from half→full saturation with bar lightness; hits dim by voice (kick −50%, snare −30%, hats −10%) — not a clock blink. MIDI fires outside the clock subscriber (pending_* isolate). Third swing blends White→app→Red. Long resets to the downbeat. Four optional voices sit on top of the three written ones and cost no pattern data — each is derived from a hit the groove already plays, and each stays silent until you give it a note (note 0 = off, which is how they ship). Clap layers under the accented snare the way house and disco stack the two. Open Hat takes over an accented hat off the beat, muting the closed hat on that step rather than smearing both transients. The toms only appear inside a fill, break or solo, and only in the back half of the bar, where they lift the snare figure into the descending run that makes a fill read as a fill — High Tom through the third beat, Low Tom to land it. With all four off, Grooves plays exactly as it did before they existed. All seven voices share the base MIDI Ch unless Ch Map is non-zero; Ch Map packs one channel per voice into seven nibbles (voice order Kick, Snare, Hats, Open Hat, Low Tom, High Tom, Clap; nibble + 1 = channel), so drum machines that expect a channel per voice can be addressed without spending a param each. Swing max % carries the direction in its sign — negative swings the offbeats early. Jack folds the old Jack, Jack Mode and CV Dest into one enum, since a CV In destination and a CV Out level shape were never live at the same time. CV In modulates Density/Feel or triggers Reset; CV Att scales input.

Long Panic clears the trail — Third interval edits never panic that hold. MIDI In always flashes white for diagnosis when muted.

Arp de Lévy ready

Lévy-flight arp — evolve, texture, flight character

Faders

  • Main — Evolve / mutation (0 = frozen)
  • Alt — Texture (density / phrase / swing feel)
  • Third — Lévy α / flight character

Jack params

  • Jack: CV Out / CV In
  • CV Out source (Jack=Out): Pitch · Gate · Velocity
  • CV Dest (Jack=In): Evolve · Texture · Reroll
  • Range, CV Att · V/Oct · Bypass quantizer

Buttons

  • Short — Reroll note pool (+ reset)
  • Long — Mute
  • Shift+Short (CV Out) — Cycle CV Out source
  • Shift+Short (CV In) — Reverse playback
  • Shift+Long — Cycle octave span 1→2→3→4

Octave LED

  • Blue · Cyan · Yellow · Red

LEDs

  • Button / Top — latch hue + level: Main = Color/Evolve · Alt = Orange/Texture · Third = Violet/α; mute = off
  • Bottom — Pitch height in Color while gated (note activity)

Params

  • MIDI CH, Base Note, Color, MIDI Out
  • Follow device tonic (default on)
  • CV pitch + MIDI (dual path)

Manual. Generative arp whose pool evolves with Lévy-flight mutations. Main bottom freezes; raise to wander. Texture shapes phrase density/length; Third sets flight character (α). Shift+Long walks octave span (button color). Jack=CV Out: Shift+Short cycles Pitch/Gate/Velocity. Jack=CV In: Shift+Short reverses; CV modulates Evolve/Texture or fires Reroll. Follow device tonic (default on) makes the device Tonic a live transpose — hold the Scene button, move Fader 5, and the arp moves with Bassment, Contura, Chord Vamp and Venn. Because the pool holds absolute notes, it is shifted by the interval rather than rerolled, so the melodic shape it has evolved into survives the transpose. Takes effect at the next phrase start.

Chord Vamp ready

Chord progressions — perform, capture, auto · MIDI + CV

Faders

  • Main (Perform) — Scrub genre degrees × 3 octaves (pitch map)
  • Main (Auto) — Tension (Meander only)
  • Alt — Genre (+ Capture clip slot if clip exists)
  • Shared axis: Dub → Disco → House → Techno → Trip-Hop → Hip-Hop → Jungle → UK Garage → Dubstep
  • Third (Auto) — Feel (laid ↔ advanced stab length)
  • Third (Perform) — Feel still stored; LEDs = blue / chord pitch

Jack params

  • Jack: CV Out · CV In Macro · CV In Panic
  • One enum — a CV In destination and CV Out were never live at once, and the freed slot is what lets Vamp grow
  • Range, V/Oct, CV Att

Buttons

  • Perform hold — Chord on; release = off (blue LEDs track pitch)
  • Auto short — Play / pause
  • Shift+Short (Perform) — Capture last N bars → Auto+Play
  • Shift+Short (Auto) — Return to Perform
  • Auto Long — Clear clip, reseed genre phrase
  • Shift+Long — Panic (both modes)

Params

  • Root, Scale, Genre, Voicing, Velocity
  • Follow device tonic (default on)
  • Auto style: Repeat / Meander
  • Start mode: Perform / Auto
  • Capture: 16 / 8 / 4 / 2 / 1 bars
  • LED: Perform = app color; Auto = orange; Hold Auto = rose (phrase pos)

Scene storage

  • 8-slot vamp + Capture clip
  • Swing 0–100 — genre-seeded; odd-16th delay (no Configurator param)
  • Feel, scrub, tension, mode, play/pause

Manual. MIDI chord vamp with optional CV jack. Shared 9-genre axis with Grooves (Dub→…→Jungle→…→Dubstep). Perform: fader = genre-unique degrees ascending across ~3 octaves; hold plays the chord (blue = pitch). Shift+Short captures recent harmony (starts quantized to 16ths, lead-in cropped to first hit; hold lengths free) into a timed clip and arms Auto. Auto: genre rhythm phrase loops — multi-chord statement (~1–2 bars) then multi-bar rest; harmony Repeat or Meander; Feel sets short stab gate (rests fixed); Swing (scene, genre-seeded) delays odd 16ths on Auto + Capture. Short = play/pause; Long clears clip / reseeds; Shift+Short → Perform; Shift+Long = Panic in either mode. Alt = genre (+ Capture slot). CV Macro = scrub/tension; Panic from CV optional. Follow device tonic (default on) turns the device Tonic into a live transpose — hold the Scene button, move Fader 5, and the harmony moves with Bassment, Contura, Venn and Arp de Lévy; the pitch class comes from the device, the octave stays with Root, and it lands on the next chord. There is no scale-follow counterpart: Scale defines the progressions, and Vamp sits at the 16-param ceiling.

Loop de Cay ready

Additive overdub loop with level decay

Faders

  • Main — Pitch (span from Base Note); spectrum LED meter. In Pitch→MIDI it transposes the CV pitch, so centre = unchanged and an unpatched jack leaves the fader in charge
  • Alt (Shift+Fader) — Decay strength: bottom = immortal, top ≈ 4 wraps (violet→red)
  • Third (Btn+Fader; gate modes while muted) — Decay mode zones (IR→UV): Random Rose · Pitch Up Orange · Pitch Down Yellow · Vel+Root Lime · Pitch Root Cyan · Velocity Blue · Gate Violet

Buttons

  • Hold (gate modes) — Note on; release = off (long notes OK). Hold+Fader = scale-degree glissando toward the fader (like Chord Vamp)
  • Shift+Short — Cycle loop length 1→2→…→8 bars (amber→cyan flash)
  • Shift+Long — Mute (red LED; decay pauses)
  • Short while muted — Unmute (re-arms)
  • Shift+Long while muted — Erase buffer (white flash)

Params / LEDs

  • Mode: Pitch→MIDI · Gate→MIDI · MIDI→MIDI · MIDI→CV · Fader→Both
  • Decay Mode: Random · Pitch Up · Pitch Down · Vel+Root (default) · Pitch Root · Velocity · Gate
  • MIDI CH / In / Out, Base Note, Span (semitones across fader)
  • Color, Range, V/Oct
  • Capture/playback hit: sharp button 80% dim (~2 PPQN) + Top white; layer meters on Top/Bottom/Button

Manual. Clocked overdub loop: play while armed to capture; each wrap applies Alt strength through the selected Decay Mode (0 = freeze forever). Pitch modes stay on the global scale. Random jitters scale pitch and only lowers velocity. Gate shortens duration toward a 16th floor. Hold the button for long notes — mute is Shift+Long. Hold+Fader glissandos through scale degrees toward the fader (Chord Vamp–style). Length is Shift+Short (1–8 bars), not Alt/Third. Third picks Decay Mode (Configurator sync). Quantized to 16ths.

ID 40

Venn ready

Dual Euclidean layers + boolean logic; scale-aware melody via Extent

Faders

  • Main — F0 pulses A · F1 pulses B (density; absolute pulse count, Bjorklund redistributes)
  • Alt (Shift) — F0 Extent (scale-degree span 0–24 from Note A) · F1 Interval (0–12 diatonic steps above the line for Ch2)
  • Third (Btn1 or Btn2 hold) — F0 length A · F1 length B (2–32; independent)
  • Rotation fixed at 0 (slots freed for Extent / Interval)
  • Division (config) — note values 4/1 … 1/32T (default 1/16)

Buttons

  • Btn1 or Btn2 hold — Third (length A/B on F0/F1)
  • Btn2 tap (no fader move) — Mute both outs
  • Shift+Btn1 — Cycle Logic OR → AND → XOR → Accnt
  • Shift+Btn2 — Toggle post-logic invert (shadow); white↔none fade like Heat Pump

Melody / LEDs

  • Note A (config) = degree 0 of the device quantizer key; Length-A walks an arch through 0…Extent scale degrees; Ch2 = same line + diatonic Interval
  • Extent 0 = monotone Note A; higher = wider arch through the A cycle (device key)
  • Division (note values), GATE %, Prob %, Humanize (Vel jitter; 0 = fixed max), MIDI CH / Note A / Interval B / Out, Color
  • Color = App Color on Btn1; Btn0 = Logic hue; Top A/B = App Color / complement (layer hits)
  • Main Btn: logic / app color · density bright · soft hit dip
  • Alt: Top+Btn dim→sat ∝ Extent / Interval (fixed hues) · Third: shortest hue btn→complement ∝ length
  • Top flashes = layer hits (Main) · Bottom flashes = logic outs (Main)
  • Jack0 = logic result + melodic line · Jack1 coupled (OR→∩, AND→△, XOR→∩, Accnt→accent) + Interval

Manual. Two independent Euclidean masks combined with boolean logic — the OXI GEN dual-layer idea with a scale-aware melodic line. Color sets Layer A; Layer B LEDs use a fixed complement. Btn1 shows logic mode, not Color. Different lengths per layer enable polyrhythmic XOR/AND patterns Euclid cannot make alone. Melody: Note A is degree 0 of the device quantizer key. Extent is the arch span in scale degrees through Length-A; Interval B is diatonic steps above that line for Ch2 (wire indices 0–12 unchanged). Extent 0 = monotone Note A. Needs clock. Prob % < 100 adds optional flakiness; 100 is fully deterministic. No pitch CV (use GenSeq for that). Venn always draws its degrees from the device Scale. **Follow device tonic** (default on) adds the missing half: hold the Scene button and move Fader 5 and both lines transpose, together with Bassment, Contura, Chord Vamp and Arp de Lévy. The pitch class comes from the device, the octave stays with MIDI Note A, and the change lands at the start of the next A-cycle rather than mid-pattern.

Voices / LEDs

  • Jamerson Orange — pocket root/fifth
  • Bootsy Pink — funk ghosts + octave drops

Manual. Genre MIDI bass on the global clock (9 shared genres with Grooves / Chord Vamp — tropes live in `genre_palette::GENRE_PROG_8`). Density reveals fill hits and freer scale degrees; Alt scrubs genre on the shared spectrum axis; Third is Feel / Groove (swing, microtiming, velocity contrast, ghost drag, gate character — depth capped by Groove max %). Notes sustain across empty 16ths until the next hit (legato when the pitch repeats). Phrases are 8 bars in AA B A′ form: the rhythmic motif repeats, harmony walks the tropes, bars 5–6 answer (shifted, more approaches), bar 7 ornaments, bar 8 breathes (no ghosts/approaches). At higher Feel the line leaves “lock” mode: live Dice mix with the step-hash for approaches, ghosts, octave punches, and accent rake; pickups appear before downbeats, soft cores get dropped for air, ghosts can become dead notes, and approaches may be chromatic or scale-neighbor. Voice × genre soft-bias: pocket players stay sparse in Jungle/UKG; busy voices thin in Dub/Techno. **Shift+Tap** plays a dedicated bass fill that walks toward the *next* bar’s chord (leading tone on the last hit) and resolves on the downbeat — Voice picks the contour (walk / arp / octave push / pedal); pocket Voices and Dub lean Pedal. Button LED goes white for the gesture (dim = pedal break). Contura draft

Melodic contour over selectable 12-TET scale sets, anchored to the device tonic

Faders

  • Main — interval width (stepwise ↔ 2–3 octave leaps across the pool)
  • Alt (Shift) — phrase length only (3–28 steps)
  • Third (Btn hold) — note density (sparse rests ↔ continuous; audible mid)

Buttons

  • Short — mute / unmute
  • Shift+Short — octave span 1→2→3→4
  • Long — next scale set
  • Shift+Long — previous scale set

Scale sets / LEDs

  • Flat list of named 12-TET sets (Ionian…Folk) — conventional interval-pattern labels, not cultural claims
  • Follow device tonic (default on); Follow device scale uses the global Key mask instead of the selected set
  • Per-set melodic feel (contour / leap / sustain) — expressivity is not a fader
  • Button hue cycles by scale index · Top = gate · Bottom = pitch height · Division via config (default 1/8)
  • Jack = CV Out (pitch) · CV In Density · CV In Interval · CV In Reset — one enum, since a CV In destination and CV Out were never live at once; CV Att scales input

Manual. Generates melodic contour phrases over selectable 12-TET pitch-class sets, anchored to the device quantizer tonic. Phrase starts and endings pull harder toward the tonic (cadence grammar); mid-phrase follows each set’s ScaleFeel. Scale-set names are conventional labels for interval patterns (Western modes and other named collections on equal footing). They are not claims about living musical practice or authentic intonation. Needs a running clock. Jack = CV Out (pitch, 1V/oct) or CV In (Density / Interval / Reset + CV Att), set in the Configurator. Gates via MIDI note on/off. Phrases mix short, medium, and longer note lengths. **Follow device tonic** (default on) turns the device Tonic into a live transpose: hold the Scene button and move Fader 5 and Contura moves with Bassment, Chord Vamp, Venn and Arp de Lévy. The note pool is rebuilt on the change, so the cadence resolves in the new key; it takes effect at the next phrase start. **Follow device scale** (default off) swaps the Scale set for the device Scale.
