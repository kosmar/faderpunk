ID 37

Harmonica ready

Monophonic root in → chord MIDI out

Faders

  • Main — Chord type
  • Alt — Spread / voicing width
  • Third — Velocity

Buttons

  • Short (no fader move) — Mute / unmute all voices
  • Alt+Short — Cycle harmony octave (−1 / 0 / +1)
  • Alt+Long — Step voicing preset

Params

  • I/O: MIDI / CV root; MIDI In/Out CH
  • CV Gate: Sustain · ms · clock divisions
  • Strum (ms), Color, Range, V/Oct
  • Near-0V CV = rest; unpatched stays silent until stable pitch
  • LEDs: IR→UV spectrum per layer; mute = red; preset flash on Alt+Long

Manual. One root (last MIDI note or pitch CV) picks the chord root; fader picks chord type; up to four MIDI voices (MIDI→CV follows highest). Not a polyphonic keyboard. Mute is a short tap; use Third (button+fader) for velocity so mute and vel don’t collide. Alt+Long walks voicing presets.
